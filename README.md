# Soffiolieve HD-2D

Demo browser amatoriale non ufficiale.

Il pacchetto completo con codice e risorse è allegato alla [release v0.8](https://github.com/kazael96/soffiolieve-hd2d/releases/tag/v0.8). Il workflow Pages scarica lo ZIP, verifica il suo SHA-256 e pubblica il sito statico. I file site-part iniziali sono un caricamento parziale conservato nella cronologia e non vengono usati dalla pubblicazione. Il file ROM originale non è incluso.

Controlli touch sugli schermi piccoli; audio attivabile dal pulsante dedicato. Copertura e limiti in ANIMAZIONI.txt e AUDIO.txt nel pacchetto.
