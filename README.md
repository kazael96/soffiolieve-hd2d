# Soffiolieve HD-2D

Demo browser amatoriale non ufficiale.

Le risorse e il codice sono nei file site-part-*.zip. Il workflow Pages li estrae e pubblica il sito statico. Non contiene la ROM originale.

La demo si usa anche su telefono: controlli touch e audio attivabile dal pulsante dedicato. Copertura e limiti sono nei file ANIMAZIONI.txt e AUDIO.txt degli archivi.
